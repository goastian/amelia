# Astian Suite application

This project is a Thunderbird/Gecko application scaffolded by Amelia.

Run `amelia download`, `amelia import`, `amelia build`, and `amelia package`
from this directory. Keep product code in `src/`, patches in `patches/`, build
configuration in `configs/`, and automation in `scripts/`.

After downloading, run `bash scripts/verify-source.sh` before bootstrapping.
